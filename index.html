FIX IT YOURSELF

Try a quick fix before calling for help.

Simple guides for common problems. If these don't work, you can request professional assistance.

Laptop is slow

A few things you can check before taking your computer to a technician.

  1. Restart the laptop.
  2. Close programs you aren't using.
  3. Check how much storage is available.
  4. Open Task Manager and check CPU/RAM usage.
  5. Run a trusted security scan.
If the problem continues, request professional help.

Phone storage is full

Free up space and improve your phone's performance.

  1. Open your phone's storage settings.
  2. Remove unnecessary large videos.
  3. Delete unused applications.
  4. Clear unnecessary downloads.
  5. Back up important files before deleting them.

Wi-Fi keeps disconnecting

Try these basic steps when your internet connection keeps dropping.

  1. Restart the router.
  2. Move closer to the router.
  3. Forget and reconnect to the Wi-Fi network.
  4. Check whether other devices have the same issue.
  5. Contact your internet provider if necessary.

Windows is frozen

Try these safe steps if your computer stops responding.

  1. Wait a few seconds to see if it responds.
  2. Try Ctrl + Shift + Esc.
  3. Close the program that is not responding.
  4. Restart Windows if necessary.

Website isn't loading

Check your connection and browser before assuming the website is broken.

  1. Refresh the page.
  2. Check your internet connection.
  3. Try another browser.
  4. Clear browser cache if necessary.
  5. Check whether other websites work.

Socket or light problem

Basic checks you can make without opening electrical wiring or equipment.

  1. Check whether there is power in the building.
  2. Check the breaker only if it is safe to do so.
  3. Try another appliance in the socket.
  4. Do not touch exposed wires.
  5. Contact a qualified electrician for electrical faults.
